## Math (KaTeX)

Inline math renders in the flow of a sentence, like the classic $E = mc^2$, or a walk-forward window size $w$.

Block math gets its own centered line:

$$
\text{PR-AUC} = \int_0^1 \text{Precision}(r)\, dr
$$

And a slightly gnarlier one, to check overflow handling on narrow screens:

$$
\hat{y} = \sigma\left(\sum_{i=1}^{n} w_i x_i + b\right) \quad \text{where } \sigma(z) = \frac{1}{1 + e^{-z}}
$$

## Code blocks

Python, to match the existing NeuraTrade posts:

```python
def walk_forward_split(data, window, step):
    for start in range(0, len(data) - window, step):
        yield data[start:start + window]
```

TypeScript, to check a second language grammar:

```typescript
interface Post {

const isPublished = (post: Post): boolean => !post.draft;
```
